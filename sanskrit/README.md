# Sanskrit Codex Archive

This folder houses Codex entries translated into **Sanskrit**.  
Each file preserves both **Devanāgarī** script and **IAST transliteration**,  
aligned precisely with the numbering of the main Codex entries.

- File naming: `entry_XXX_title_sa.md` → Devanāgarī + IAST  
- Optionally: `entry_XXX_title_sa_bilingual.md` → parallel edition (Devanāgarī + IAST side-by-side)  

These translations are intended for archival, comparative study, and resonance with  
the oldest continuous linguistic system of philosophy and pattern.

## संस्कृतं

अत्र कोडेक्सस्य संस्कृतभाषानुवादाः संगृहीताः।
